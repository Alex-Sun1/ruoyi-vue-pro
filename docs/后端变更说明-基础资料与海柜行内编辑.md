# 后端变更说明：基础资料补充与海柜行内编辑

## 1. 本次已实现范围

- BASE 基础资料：渠道、业务类型、增值服务三套 CRUD、分页、启停、精简列表、导出接口。
- BASE 平台地址：新增 `GET /base/platform-address/simple-list`，支持按 `platformId` 或 `platformCode` 过滤，并返回可带出地址的字段。
- OMS 海柜：新增 `PUT /oms/container/inline-update`，用于列表行内编辑。
- OMS 建柜带订单：订单行支持保存平台地址快照字段，平台地址下拉选中后带出的国家、州、市、地址、邮编等会落库。
- OMS 渠道显示：海柜列表渠道名称改为读取新的 `base_channel`，不再依赖旧 `base_sales_channel`。

## 2. 需要执行的 SQL

请按环境执行以下脚本：

- `sql/mysql/base-master-data-channel-business-vas.sql`
  - 创建 `base_channel`
  - 创建 `base_business_type`
  - 创建 `base_value_added_service`
  - 增加对应菜单与权限点

- `sql/mysql/oms-container-inline-platform-address-alter.sql`
  - 给 `cargo_order` 增加平台地址快照与地址二字段
  - 给 `oms_container_terminal_info` 增加 LFD、chassis free 字段
  - 给 `oms_container_transport_info` 增加预约、到仓、司机、车牌、车架、dock 字段

> 注意：如果生产库已经存在同名列，需要 DBA 先检查再执行 ALTER。

## 3. 前端对接接口

### 3.1 渠道

- `GET /base/channel/page`
- `GET /base/channel/get?id={id}`
- `POST /base/channel/create`
- `PUT /base/channel/update`
- `PUT /base/channel/update-status`
- `DELETE /base/channel/delete?id={id}`
- `GET /base/channel/simple-list?status=0&channelType=&containerMode=`
- `GET /base/channel/export`

权限：
`base:channel:list`, `base:channel:add`, `base:channel:edit`, `base:channel:remove`, `base:channel:export`

### 3.2 业务类型

- `GET /base/business-type/page`
- `GET /base/business-type/get?id={id}`
- `POST /base/business-type/create`
- `PUT /base/business-type/update`
- `PUT /base/business-type/update-status`
- `DELETE /base/business-type/delete?id={id}`
- `GET /base/business-type/simple-list?status=0&businessCategory=&operationFlowType=`
- `GET /base/business-type/export`

权限：
`base:business-type:list`, `base:business-type:add`, `base:business-type:edit`, `base:business-type:remove`, `base:business-type:export`

### 3.3 增值服务

- `GET /base/vas/page`
- `GET /base/vas/get?id={id}`
- `POST /base/vas/create`
- `PUT /base/vas/update`
- `PUT /base/vas/update-status`
- `DELETE /base/vas/delete?id={id}`
- `GET /base/vas/simple-list?status=0&serviceCategory=`
- `GET /base/vas/export`

权限：
`base:vas:list`, `base:vas:add`, `base:vas:edit`, `base:vas:remove`, `base:vas:export`

### 3.4 平台地址精简列表

`GET /base/platform-address/simple-list`

参数：
- `platformId`：可选
- `platformCode`：可选，例如 `AMAZON`
- `status`：可选，默认 `0`

返回主要字段：
`id`, `platformId`, `platformCode`, `platformName`, `addressCode`, `addressType`, `nameEn`, `nameDisplay`, `countryCode`, `stateCode`, `city`, `addressLine1`, `addressLine2`, `zipCode`

## 4. 海柜行内编辑

`PUT /oms/container/inline-update`

请求：
```json
{
  "id": 1,
  "field": "terminal.pickupLfd",
  "value": "2026-05-21"
}
```

允许字段：
- 主表：`blNo`, `containerType`, `channelId`, `customerId`, `carrierCode`, `vesselName`, `voyageNo`, `routeCode`, `polCode`, `podCode`, `csUserId`, `eta`, `atd`, `ata`, `remark`
- 码头：`terminal.availableAt`, `terminal.pickupLfd`, `terminal.returnLfd`, `terminal.chassisFreeUntil`, `terminal.examStatus`, `terminal.examStartAt`, `terminal.examEndAt`, `terminal.isOnHold`, `terminal.holdReason`
- 派送：`transport.appointmentTime`, `transport.etaWarehouse`, `transport.requiredWarehouseAt`, `transport.driverName`, `transport.truckPlate`, `transport.chassisNo`, `transport.dockNo`

不允许行内直接改 WMS/TMS 已回传时间，例如 `pickedUpAt`, `arrivedAt`, `emptyReportedAt`, `returnedAt`。
